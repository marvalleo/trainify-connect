# Product Context

"Trainify Connect" resuelve la necesidad de los usuarios que entrenan con un enfoque en la sobrecarga progresiva y necesitan una herramienta más ágil que una hoja de cálculo tradicional, pero más personalizada que las aplicaciones de fitness genéricas.

## Problemas que resuelve
- **Falta de seguimiento de series**: Muchos trackers solo guardan el mejor set. Este permite marcar cada serie (1, 2, 3, 4+) de forma visual.
- **Dificultad para ver el volumen total**: Automatiza el cálculo de `Kg x Reps` para asegurar que el volumen de trabajo aumente con el tiempo.
- **Dependencia de internet**: Funciona totalmente offline usando almacenamiento local.

## Experiencia de Usuario (UX)
- **Vista de Entrenamiento**: Dividida por categorías (Superior, Inferior, Espalda/Hombro).
- **Indicadores de Sesión**: Círculos neón que se iluminan al completar series hoy.
- **Gráficas Integradas**: Acceso rápido al historial visual sin cambiar de página.
