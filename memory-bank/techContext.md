# Technical Context

## Tecnologías Utilizadas
- **Frontend**: HTML5, CSS3 (Tailwind CSS), JavaScript (ES6+).
- **Librerías Externas**: 
  - [Chart.js](https://www.chartjs.org/): Generación de gráficas de carga y volumen.
  - [FontAwesome](https://fontawesome.com/): Iconografía.
- **Almacenamiento**: `localStorage` del navegador (Llaves: `trainify_records`, `trainify_exercises`).
- **Nube**: Google Drive (Carpeta: `Trainify Connect Data`).
- **Autenticación**: Google OAuth 2.0.
- **APIs**: Google Drive API.

## Limitaciones y Restricciones
- **Navegador**: Depende de las capacidades de almacenamiento del navegador (aprox. 5MB para localStorage).
- **Dispositivo**: Optimizado para uso móvil (Mobile First).
